# /cards — Generated mechanism cards

## What lives here

`{id}.md` — one human-readable card per full L1 mechanism record (summary,
evidence, implementations table, metrics, constraints, relations).

**Generated output only.** Never create or edit files here by hand — cards
are projections of `/registry` produced by `tools/render-cards.ts`
(`npm run cards`). To change a card, change the registry record and re-render.

## Filled by

`npm run cards`, once `tools/render-cards.ts` and the first full record
(LA-01) exist.

## Phase

July (baseline, after the registry data step).
