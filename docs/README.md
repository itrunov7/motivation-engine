# /docs — Foundation documents

## What lives here

The library documents of the Motivation Engine, as Markdown:

- `manifesto.md`
- `ontology-as-science.md`
- `architecture.md`
- `runtime-flow.md`
- `roadmap.md`
- `connectors-runbook.md` — the operator's manual for the source-connector
  fleet (D-031)

The first five are the owner-authored foundation set (SPEC §3.6). The
connectors runbook is an operational manual maintained alongside the ops layer.
The app renders every file here at `/docs/[slug]`; it never edits their content.

## Filled by

Ported unchanged from the owner-provided English versions during the data
step of the baseline build. Content changes come only from the owner.
