# /docs — Foundation documents

## What lives here

The five foundation documents of the Motivation Engine, as Markdown:

- `manifesto.md`
- `ontology-as-science.md`
- `architecture.md`
- `runtime-flow.md`
- `roadmap.md`

Content is authored by the owner. The app renders these files at `/docs/[slug]`;
it never edits their content.

## Filled by

Ported from owner-provided English versions (currently staged in
`content-inbox/`) during the data step of the baseline build.
