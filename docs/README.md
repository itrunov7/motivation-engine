# /docs — Foundation documents

## What lives here

The library documents of the Motivation Engine, as Markdown:

- `manifesto.md`
- `ontology-as-science.md`
- `architecture.md`
- `runtime-flow.md`
- `roadmap.md`
- `connectors-runbook.md` — the operator's manual for the source-connector
  fleet (D-031)
- `s7-drafting-brief.md` — the hand-off contract for drafting the S7 candidates
- `computed-grading.md` — a PROPOSAL for computing evidence grades from the
  corpus instead of asserting them (D-114); nothing in it is implemented
- `retag-packet.md` — the category retag and the contradiction vocabulary,
  measured and not applied, for the owner session (D-135)
- `owner-session-2026-07-31.md` — the agenda for that session, linking the
  four artifacts it decides on

The first five are the owner-authored foundation set (SPEC §3.6). The
connectors runbook is an operational manual maintained alongside the ops layer.
The app renders the six files listed in `DOC_SLUGS` at `/docs/[slug]` and never
edits their content; the review documents below that list are read in git,
because they are session material rather than library documents.

## Filled by

Ported unchanged from the owner-provided English versions during the data
step of the baseline build. Content changes come only from the owner.
